List tags in HTML

List Tag:

There are three main types of lists.each using a specific container tag combined with chilad elements to structure information

There are 3types of list in html:

  1. Ordered list (tag: ol)
  2. Unordered list (tag: ul)
  3. Descripton list (tag: dl)

Ordered list (ol):

Used for items that follow a specific sequence or hierarchy. By default, these items are marked with numbers. Like unordered lists, individual items use the

  • tag.

    List of 5 fruits with ordered list:

    1. Apple
    2. watermelon
    3. pineapple
    4. jackfruit
    5. Orange

    Unordered List (ul):

    Used for items where the order does not matter. By default, these items are marked with bullet points (discs). Each item inside the list is defined using the

  • (list item) tag.

    List of 5 flowers with unordered list:

    • Merigold
    • Rose
    • China Rose
    • Lotus
    • Jasmine

    Description list:

    Used for a collection of terms and their corresponding descriptions (like a dictionary or glossary).
    dl:outlines the complete description list.
    dt: defines the description term.
    dd: provides the definition or description.

    Water Lily
    The national flower of Bangladesh.
